 Python Fitness Tracker

This project is a simple **Python-based fitness tracker** that allows users to record their workouts, duration, and calories burned.  
It’s a lightweight console program designed to help track fitness progress using basic scripting and logic — no external libraries or databases required.
The current state works as intended, there will be additions as well as user-interface add-ons as I work on this.

---

## 🚀 How to Run

1. Make sure you have **Python 3.11** or later installed.
2. Open a terminal in the project folder.
3. Run the program:
   ```bash
   py PersonalProject.py
